# План разработки: Flappy Bird (Android)

Дата: 2026-07-26

## Цель
Нативная Android-игра в стиле Flappy Bird на Kotlin. Управление одним касанием:
тап заставляет птицу «взмахнуть» вверх, гравитация тянет вниз, нужно пролетать
между трубами и набирать очки.

## Стек
- Kotlin + Gradle (Kotlin DSL)
- Рендеринг: `SurfaceView` + отдельный игровой поток (`GameThread`)
- Графика: рисование примитивами на `Canvas` (без внешних ассетов — всё
  self-contained, ничего не нужно докачивать)
- minSdk 24, targetSdk 36

## Архитектура
```
MainActivity            — точка входа, жизненный цикл, ставит GameView экраном
 └─ GameView            — SurfaceView + игровой цикл, ввод, рендеринг, состояния
     ├─ GameThread      — цикл update/draw с фиксированным шагом по времени (dt)
     ├─ Bird            — физика птицы (позиция, скорость, гравитация, взмах)
     └─ Pipe            — пара труб с зазором, движение, коллизии, начисление очка
```

## Игровые состояния
- `READY`     — заставка «Tap to start», птица парит
- `PLAYING`   — идёт игра
- `GAME_OVER` — экран проигрыша, рекорд, тап для рестарта

## Механика
- Гравитация постоянно тянет птицу вниз; тап задаёт импульс вверх.
- Трубы едут справа налево с постоянной скоростью, спавнятся с интервалом.
- Зазор между трубами по вертикали — случайная позиция.
- Очко +1 при прохождении трубы.
- Коллизия: круг птицы vs прямоугольники труб + пол и потолок → GAME_OVER.
- Рекорд хранится в `SharedPreferences`.

## Все величины масштабируются от размеров экрана
Скорости и размеры задаются в долях от ширины/высоты, физика считается в
пикселях/сек через delta-time → одинаково на любом разрешении и FPS.

## Разделение труда между агентами
- **Визуальный агент** — рендеринг, палитра, форма птицы/труб/фона, текст, UX.
- **Технический агент** — игровой цикл, физика, коллизии, состояния, ввод,
  сохранение рекорда, жизненный цикл.

Подробности — в `../Agents/`.
