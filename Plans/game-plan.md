# План разработки: Flappy Bird (Android)

Дата: 2026-07-26

## Цель
Нативная Android-игра в стиле Flappy Bird на Kotlin. Управление одним касанием:
тап заставляет птицу «взмахнуть» вверх, гравитация тянет вниз, нужно пролетать
между трубами и набирать очки.

## Стек
- Kotlin + Gradle (Kotlin DSL)
- Рендеринг: `SurfaceView` + отдельный игровой поток (`GameThread`)
- Графика: рисование примитивами на `Canvas` (без внешних ассетов — всё
  self-contained, ничего не нужно докачивать)
- minSdk 24, targetSdk 36

## Архитектура
```
MainActivity            — точка входа, жизненный цикл, ставит GameView экраном
 └─ GameView            — SurfaceView + игровой цикл, ввод, рендеринг, состояния
     ├─ GameThread      — цикл update/draw с фиксированным шагом по времени (dt)
     ├─ Bird            — физика птицы (позиция, скорость, гравитация, взмах)
     └─ Pipe            — пара труб с зазором, движение, коллизии, начисление очка
```

## Игровые состояния
- `READY`     — заставка «Tap to start», птица парит
- `PLAYING`   — идёт игра
- `GAME_OVER` — экран проигрыша, рекорд, тап для рестарта

## Механика
- Гравитация постоянно тянет птицу вниз; тап задаёт импульс вверх.
- Трубы едут справа налево с постоянной скоростью, спавнятся с интервалом.
- Зазор между трубами по вертикали — случайная позиция.
- Очко +1 при прохождении трубы.
- Коллизия: круг птицы vs прямоугольники труб + пол и потолок → GAME_OVER.
- Рекорд хранится в `SharedPreferences`.

## Все величины масштабируются от размеров экрана
Скорости и размеры задаются в долях от ширины/высоты, физика считается в
пикселях/сек через delta-time → одинаково на любом разрешении и FPS.

## Разделение труда между агентами
- **Визуальный агент** — рендеринг, палитра, форма птицы/труб/фона, текст, UX.
- **Технический агент** — игровой цикл, физика, коллизии, состояния, ввод,
  сохранение рекорда, жизненный цикл.

Подробности — в `../Agents/`.

## Пиксельный стиль + экран загрузки (2026-07-27)
- Вся графика переведена в **пиксель-арт**: спрайты из квадратов без сглаживания
  (`Paint` без ANTI_ALIAS), чанковые трубы (рамка + блик + тень), пиксельная
  земля с травой/комьями, небо с пиксельным солнцем и облаками (параллакс).
- **Курица** — пиксельный спрайт 13×12 с **анимацией взмаха крыльями** (3 кадра
  `wingUp/wingMid/wingDown`, накладываются на тело, машет и в READY).
- **Экран загрузки** (`State.LOADING`, ~2.2 с при первом запуске): название
  `FLAPPY CHICKEN` чуть выше центра, верхняя половина жёлтая / нижняя оранжевая
  (через `clipRect`), под ним жёлтая **полоса загрузки**, заполняется по времени.
- Имя приложения → **Flappy Chicken**.
- **Пиксельный текст** (весь UI, включая кириллицу): строка рисуется мелким
  шрифтом в `Bitmap`, затем растягивается целочисленно nearest-neighbor
  (`isFilterBitmap=false`) → чёткие «пиксели» без ручной прорисовки букв. Есть
  кэш битмапов (`textCache`), чтобы не аллоцировать каждый кадр.

## Проработка визуала под референс + жёлтая птица (2026-07-27)
- Уровень детализации подтянут под пиксель-арт-референс: слоистое небо (полосы),
  пушистые облака с тенью, мерцающие звёзды-искры, пиксельное солнце, детальные
  деревья (3 тона листвы + ствол, параллакс), многослойная земля (трава с
  бугристой кромкой + грунт с прожилками и камешками).
- **Курица → жёлтая птица** (спрайт 13×11: тело, блик, белок, зрачок, клюв,
  обводка) с анимацией взмаха крыла.
- **Объёмный текст**: тёмная обводка (8 направлений) + вертикальный
  жёлто-оранжевый градиент — как «GAME OVER» на референсе. Используется для
  заголовков `FLAPPY/BIRD` (загрузка), `FLAPPY BIRD` (старт), `GAME/OVER`.
- Название игры/приложения → **FlappyBird**.
- Проверено на эмуляторе (Medium_Phone): загрузка, геймплей, Game Over.

## Город, темы, иконка, сплэш (2026-07-27)
1. **Шрифты** — пиксельный текст переведён на моноширинный жирный (`Typeface.MONOSPACE`)
   с letter-spacing → читаемее; остальной визуал подтянут.
2. **Убрано мерцание неба** — звёзды теперь статичные (без анимации размера),
   рисуются только ночью.
3. **Локация → город**, две темы (день/ночь): небоскрёбы с окнами (2 слоя,
   параллакс), тротуар вместо травы, солнце днём / луна+звёзды ночью. Палитра в
   `applyTheme()`, сохранение в `SharedPreferences` (ключ `night`). Кнопка
   **«Theme»** внизу главного меню меняет тему и сама меняет цвет (день —
   светлая с тёмным текстом, ночь — тёмная со светлым).
4. **Иконка приложения** — пиксельная жёлтая птица на голубом небе (адаптивная:
   `ic_launcher_foreground` — птица, `ic_launcher_background` — небо; сгенерированы
   скриптом из спрайта).
5. **Стартовый фон** — `windowBackground`/системный сплэш = небо игры (`sky_blue`)
   вместо белого экрана Android; на Android 12+ по центру круглая иконка-птица,
   а название игры по центру показывает экран загрузки сразу после.
   Векторы птицы и логотипа генерятся скриптом (5×7 пиксель-шрифт).

## Звёзды, тема заголовка, дома-препятствия (2026-07-27)
1. **Мерцание звёзд** возвращено (ночью): размер каждой звезды пульсирует по
   `sin` со своей фазой.
2. **Ночной заголовок** — градиент стал сине-фиолетовым (день остаётся
   жёлто-оранжевым); цвета `titleTop/titleBottom` задаёт `applyTheme()`, кэш
   текста сбрасывается при смене темы.
3. **Трубы → дома-препятствия**, меняются по теме: корпус с окнами (устойчивый
   узор по `Pipe.seed`) + карниз-крыша у проёма. День — тёплый кирпич со светлыми
   окнами; ночь — тёмный фиолетовый кирпич со светящимися окнами. Цвета в
   `applyTheme()` (obsBody/obsEdge/obsRoof/obsWinLit/obsWinDark).
