# Agents

По требованию проекта работа разделена между двумя агентами. Здесь хранятся
их роли, зоны ответственности и журнал выполненных задач.

- [visual-agent.md](visual-agent.md) — визуальная часть игры
- [technical-agent.md](technical-agent.md) — техническая часть игры

Граница между ними: технический агент отвечает за *что происходит* (состояние
мира, физика, правила), визуальный — за то, *как это выглядит* (пиксели на
экране). Общий контракт — объекты `Bird` и `Pipe` и их поля: технический агент
их обновляет, визуальный рисует.
